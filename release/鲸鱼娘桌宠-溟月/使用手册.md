# 鲸鱼娘桌宠「溟月」使用手册

一个会动的桌面宠物（鲸鱼娘），常驻屏幕右下角。可以拖动、点击互动，还会根据 AI 助手的工作状态切换动画（待机 / 思考 / 干活 / 庆祝），任务完成时用「碧蓝档案 · 佳代子」的声音报一句完工语音。

---

## 一、需要准备

- **Windows 10 / 11**
- **Node.js**（LTS 版，自带 npm）：到 https://nodejs.org/ 下载，一路"下一步"装完即可

---

## 二、安装（只需两步）

**第 1 步**：安装 Node.js（上面下载的那个）

**第 2 步**：打开本文件夹里的 `electron` 文件夹，在地址栏输入 `cmd` 回车（或右键 → "在终端中打开"），执行：

```
npm install
```

国内网络慢就用镜像源：

```
npm install --registry=https://registry.npmmirror.com
```

等待下载完成即可（Electron 二进制约 100~200MB，视网速等几分钟）。

> 装过一次就不用再装了，以后直接启动。

---

## 三、启动

三种方式任选：

| 方式 | 操作 | 说明 |
|---|---|---|
| ① 推荐 | 双击 `start-pet.vbs` | 无黑窗口，静默启动 |
| ② | 双击 `start-pet.bat` | 有命令行窗口 |
| ③ | 进 `electron` 文件夹执行 `npm start` | 调试用 |

桌宠会出现在**屏幕右下角**。托盘图标右键可退出。

---

## 四、玩法

- **拖动**：鼠标按住，拖到任意位置
- **点击**：挥手互动
- **动画状态**：

| 状态 | 表现 |
|---|---|
| 待机 | 漂浮呼吸，偶尔自己挥挥手、歪歪头 |
| 干活 | 打字顿挫，前倾小顿 |
| 思考 | 大幅缓慢左右歪头 + 气泡"唔…让我想想" |
| 等待 | 期待小跳 |
| 出错 | 泄气下沉 |
| 庆祝 | 跳跃 + 撒花 + 完工语音（随机一句） |

## 五、完工语音

5 句完工语音都是「碧蓝档案」**佳代子**（便利屋 68）的日语音色，用 TTS-Online 在线生成：

| 文件 | 内容 |
|---|---|
| voice-1.mp3 | 完了しました！お疲れ様です！（完成了！辛苦了！） |
| voice-2.mp3 | はい、完了です。（是的，完成了。） |
| voice-3.mp3 | ちゃんとやりましたよ。（好好做完了哦。） |
| voice-4.mp3 | おつかれさま。終わったよ。（辛苦了，结束了哦。） |
| voice-5.mp3 | お待たせしました。完了です。（让你久等了，完成了。） |

**想换成自己的语音**：直接覆盖 `assets` 文件夹里的 `voice-1.mp3` ~ `voice-5.mp3`（保持同名、mp3 格式即可），重启桌宠生效。

## 六、让桌宠自动切换状态（进阶，可选）

桌宠本体是**独立程序**，默认只有待机动画和点击互动。

要让它根据 AI 助手的工作状态**自动切换动画、自动庆祝**，需要配合 Hana 平台（本地 AI 助手环境）的事件桥接插件：

1. 把交付包里的 `hana-bridge` 文件夹，复制到 Hana 的插件目录（`C:\Users\<你的用户名>\.hanako\plugins\` 下）
2. 重启 Hana，插件会自动订阅事件总线，把「思考 / 干活 / 失败 / 完成」映射成桌宠动画

**不用 Hana 的话，桌宠就是一只纯装饰桌宠，不影响使用。**

## 七、常见问题

**Q：双击没反应？**
A：① 确认 Node.js 装好了（命令行执行 `node -v` 有版本号）；② 确认 `electron` 文件夹里跑过 `npm install`。

**Q：提示 `port 8999 already in use`？**
A：说明桌宠已经在运行了（单实例保护），忽略即可，或把旧的关掉再启动。

**Q：桌宠位置 / 大小怎么改？**
A：打开 `electron\main.js`，找 `createWindow()` 里的 `width`、`height` 和 `setPosition(...)`，改数字即可。

**Q：气泡文字怎么改？**
A：打开 `electron\pet.html`，搜 `BUBBLES`，改对应文案。

**Q：想完全退出？**
A：托盘图标右键 → 退出。没有托盘图标就去任务管理器结束 `electron.exe`。

## 九、技术细节（写给好奇的人）

- **透明置顶无边框窗口**，Electron 实现，常驻用户会话
- **本地 HTTP 服务** `127.0.0.1:8999`：
  - `GET /jiadaizi-pet/state` 查当前状态
  - `POST /jiadaizi-pet/set-mode` 驱动状态（idle / working / review / waiting / failed / celebrating）
  - `POST /jiadaizi-pet/reload` 热重载页面（改 pet.html 后不用重启进程）
  - `GET /spritesheet.png`、`GET /voice-N.mp3` 素材路由（白名单防穿越）
- **状态机 6 种**：idle / working / review / waiting / failed / celebrating
- **素材精灵图是 9 个单帧动作**（画布左侧一列），动态全靠程序 CSS transform 变换，没有逐帧序列图
- **庆祝动画 4.8 秒**自动回落待机，完工语音每次随机一句
